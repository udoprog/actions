# actions

GitHub actions by udoprog. Each action lives on its own branch:

- `udoprog/actions@kick` installs [kick](https://github.com/udoprog/kick).
- `udoprog/actions@trug` installs [trug](https://github.com/udoprog/trug).

```yaml
- uses: udoprog/actions@kick
- uses: udoprog/actions@trug
```

See each branch's README for its inputs.
